# Архитектура и соответствие источникам

```
Среда ── matrix_144 (где: ячейка 1..144, путь по подсеткам; когда: индекс циклов)
   │
   ▼
Акт Творения (svet.py, 22 шага) ──► артефакты шагов (JSON)
   │        ▲ reopen(): обратная связь
   ▼        │
Цикл ФДЛ (fdl.py): тезис ↔ антитезис (+условия) → синтез / открытая задача
   │
   ├─ octahedron.py : перекосы Дух/Творение, Сила/Вера, Искусство/Наука → вопросы для цикла
   ├─ priorities.py : какие 4 из 24 направлений в фокусе на шаге приоритета
   └─ sip.py        : кто работает (ЛОГОС/ХАОС/КОСМОС), баланс 49–49–2, допуск диалога
```

## Что изменено относительно исходных файлов
* `grid_allocator`: пример «ячейка 80 = Николаевский сектор» был ошибочным (ячейка 80 — 0°…15° с.ш.); Николаев — ячейка **116**. Добавлены `locate`, `locate_path`, `neighbors`, `area_weight`, `distribute`.
* `cycles_sync`: параметры вынесены в аргументы; переименовано `planetary_friction_risk` → `friction_index`; добавлены валидация и оговорка о статусе индекса.
* Формулировки `sip_rules/README.md` нейтрализованы (без полемики), смысл сохранён.
* Заглушки из набросков (хардкод «Орион активен», вызов несуществующего `metoeprocessor.py`) не перенесены: среда считается из реальных модулей.
* Таблица 4.Н исходника содержит опечатку (в ПР4, шаг 5 указано «2.9.20.21», по закономерности — «2.9.20.23»); код строит матрицу по закономерности.
