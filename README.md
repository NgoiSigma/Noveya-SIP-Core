# Noveya-SIP-Core

Исполняемое ядро практик **НОВЕЯ-СИП** (Солидарные Игровые Практики): формальная диалектическая логика (ФДЛ)
и программная модель **Оболочка СВЕТ** (система векторов единства типологики) в виде небольшой библиотеки на чистом Python (без зависимостей).

Это **детерминированный слой метода**: то, что ИИ «Протоновея» (или человек) может вызывать, чтобы рассуждение было
проверяемым — с условиями, статусами суждений, порядком шагов и журналом. Сама языковая модель в репозиторий не входит.

## Структура

```
noveya/            ядро
  fdl.py           ФДЛ: суждения, модальности, достоверность≠истинность, цикл Тезис–Антитезис–Синтез
  svet.py          Оболочка СВЕТ: Акт Творения (22 шага) как конечный автомат
  octahedron.py    общая модель созидания (октаэдр в сфере), индекс гармонии, перекосы → вопросы для ФДЛ
  priorities.py    24 направления и матрица Курса Приоритетов 6×6
  sip.py           триада ЛОГОС/ХАОС/КОСМОС, баланс 49–49–2, фильтр диалога, очистка буфера
  avatarus.py      адаптер Σ-Avatarus (символический слой, Камертон)
  demo.py, cli.py  сквозной пример и командная строка
matrix_144/        сетка геоида 12×12 = 144 ячейки; условный индекс циклов
sip_rules/         инструкция оператора СИП и манифест (JSON)
config/            шаблон названий 24 направлений
docs/              архитектура и соответствие источникам
tests/             pytest
```

## Быстрый старт

```bash
pip install -e ".[dev]"
pytest
python -m noveya demo
python -m noveya cell 46.97 31.99 --depth 3     # Николаев → ячейка 116, подъячейки
python -m noveya steps
python -m noveya priorities
```

```python
from noveya.fdl import DialecticCycle, Judgement

t = Judgement("координация", "эффективна", conditions={"масштаб": "страна"}, credibility=.7)
a = Judgement("координация", "эффективна", affirmed=False, conditions={"масштаб": "громада"}, credibility=.7)
print(DialecticCycle().run(t, a).render())   # → разделение по условиям
```

## Границы применимости (важно)

* `matrix_144/cycles_sync.py` — **условный индекс**, а не прогноз. Связь солнечной активности с социальными
  процессами — гипотеза Чижевского; пороги не откалиброваны (при значениях по умолчанию режим `ACTIVE_SYNTHESIS` включается почти всегда).
* Сетка 144 ячеек грубая (15°×30°): почти вся Украина — ячейка 116. Для локальной работы используйте `locate_path(..., depth>=2)`.
* Названия 24 направлений в код не зашиты — заполните `config/directions.json` по таблице 3.Н «Формальной диалогики».
* Движок ФДЛ не «выдумывает» синтез: новое качество (единство) задаёт человек параметром `bridge`.

## Источники и авторство

Логика и структуры основаны на трудах А. Е. Кашеваровой: «Теоретические основы „Оболочки СВЕТ“» (Николаев, 2019) и
«Формальная диалогика» (1994, ред. 2008). Перед публикацией убедитесь, что использование этих материалов
в репозитории согласовано с правообладателями, и добавьте файл `LICENSE` по вашему выбору.
