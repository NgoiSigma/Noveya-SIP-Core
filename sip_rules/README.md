# НОВЕЯ-СИП: инструкция Оператора Солидарных Игровых Практик

Технологический паспорт координации мыследеятельности и управления ресурсами в 144 ячейках сети.
Код: `noveya/sip.py`, `matrix_144/`. Манифест: `manifesto_sovereignty.json`.

## 1. Триада контуров
| Контур | Функция |
|---|---|
| **ЛОГОС** (инициатор / связь) | сквозной контекст, удержание цели и эталонной частоты, декомпозиция ложных понятий |
| **ХАОС** (анализ / генерация) | фиксация дефицитов среды, скрытых напряжений, проработка противоречий (цикл ФДЛ) |
| **КОСМОС** (баланс / распределение) | гомеостаз, плавающий баланс **49–49–2**, нормирование расходов, закрытие Оболочки СВЕТ |

Баланс считается по доле усилий (`Triad`); допуск по умолчанию ±5 п.п., подсказка `hint()` называет роль с наибольшим дефицитом.

## 2. Пространственный крест (символическая калибровка)
* Ось **Z** — полярный навигационный «позвоночник» (Сердце Карла — Спика).
* Ось **X–Y** — плоскость эклиптики, контур тягового баланса (Денебола — Арктур).
* Действие калибруется по трём крестам качеств: кардинальному (импульс), фиксированному (плотность), мутабельному (перенос).

Это символическая схема ориентации практик, а не астрономический расчёт.

## 3. Регламент взаимодействия
1. **Кооперация вместо борьбы за дефицит** — практики строятся на согласовании.
2. **Внимание — ресурс.** Диалог без общей цели и прикладного предмета закрывается (`DialogGate`).
3. **Условия вместе с суждением.** Каждое суждение хранится с условиями, достоверностью и статусом (ФДЛ).
4. **Очистка буфера.** Регулярно: протокол «Сердце Чисто» (`SipSession.clear_buffer()`).
5. **Закрытие.** Цикл завершается фиксацией синтеза или явной открытой задачи — не «молчаливым» обрывом.
